# E-News Express A/B Testing

Applied statistics project using hypothesis testing to evaluate a redesigned landing page for E-News Express, an online news portal.

## Business Context

E-news portals let readers get fast updates on global events, retrieved electronically and transmitted through various technologies. E-News Express wants to grow its subscriber base and ran an A/B test comparing its existing landing page against a new, redesigned one, to see whether the new design leads to more time spent on the page and more subscription conversions.

## Objective

Use statistical hypothesis testing (e.g. t-tests, chi-square tests) on the A/B test data to determine whether the new landing page performs significantly better than the old one, and recommend whether to roll it out.
